Server vorbereiten

CounterStrikeSharp läuft als Erweiterung von Metamod:Source. Du brauchst also beides:

  1. Metamod:Source (Version 2.x) herunterladen und nach game/csgo/ entpacken.
  2. In game/csgo/gameinfo.gi unter SearchPaths direkt nach Game_LowViolence die Zeile Game csgo/addons/metamod eintragen.
  3. CounterStrikeSharp in der Variante with-runtime (beim ersten Mal) von GitHub herunterladen und ebenfalls nach game/csgo/ entpacken.
  4. Server starten und in der Konsole meta list eingeben – CounterStrikeSharp sollte aufgelistet sein.

Erstes Plugin

Ein Plugin ist ein normales C#-Projekt. Auf der Startseite ist bereits ein Demo-Projekt geladen – klick einfach auf Jetzt kompilieren. Die zwei Dateien sehen so aus:

<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="CounterStrikeSharp.API" Version="*" ExcludeAssets="runtime" />
  </ItemGroup>
</Project>
using CounterStrikeSharp.API.Core;

public class HalloPlugin : BasePlugin
{
    public override string ModuleName => "Hallo";
    public override string ModuleVersion => "1.0.0";

    public override void Load(bool hotReload)
    {
        Console.WriteLine("Hallo Welt!");
    }
}

Neue Dateien legst du im Editor über Neue Datei an. Befehle definierst du mit [ConsoleCommand("css_name")], Ereignisse mit [GameEventHandler].

Projekt richtig packen

  • Pack den ganzen Projektordner in ein .zip – mit der .csproj und allen .cs-Dateien.
  • bin/, obj/ und .git/ werden automatisch ignoriert, du musst sie nicht entfernen.
  • Verweist dein Projekt auf ein anderes Projekt (z. B. ein Git-Submodul), muss dieser Ordner ebenfalls im .zip sein. GitHub „Download ZIP“ enthält keine Submodule – füge den Ordner selbst hinzu.
  • Liegen mehrere .csproj im Archiv, kannst du das Hauptprojekt auswählen.
  • Verweist die .csproj per HintPath auf eine lokale CounterStrikeSharp.API.dll, wird das automatisch durch das NuGet-Paket ersetzt.

Welche Version?

Die API-Version sollte zur CounterStrikeSharp-Version auf deinem Server passen. Gib in der Server-Konsole meta list oder css_plugins list ein, um sie zu sehen. Im Zweifel nimm die neueste Version.

Neuere CounterStrikeSharp-Versionen setzen ein neueres .NET voraus. Passt dein Projekt nicht zur gewählten Version, schlägt der Compiler automatisch eine passende Version vor oder bietet an, das Ziel-Framework umzustellen.

Release ist für den Live-Server gedacht. Debug enthält zusätzliche Debug-Informationen (.pdb) und ist nur zur Fehlersuche sinnvoll.

Plugin installieren

Die heruntergeladene .zip ist schon richtig aufgebaut. Entpacke sie in game/csgo/ – das Plugin landet dann in:

game/csgo/addons/counterstrikesharp/plugins/DeinPlugin/DeinPlugin.dll

Danach den Server neu starten oder in der Konsole css_plugins load DeinPlugin eingeben.

Häufige Fehler

Plugin wird nicht geladen: Ordnername und DLL-Name müssen gleich sein. Prüfe die Server-Konsole bzw. die Logs unter addons/counterstrikesharp/logs/.

CS0246 – Typ oder Namespace nicht gefunden: Es fehlt ein NuGet-Paket, ein using oder eine Projektreferenz.

CS0117 / CS1061 – Member existiert nicht: Die API hat sich geändert. Das Plugin wurde meist für eine ältere CounterStrikeSharp-Version geschrieben – wähle diese Version aus.

NU1202 – Paket nicht kompatibel: Ziel-Framework und API-Version passen nicht zusammen.

CS0006 / Projekt nicht gefunden: Ein referenziertes Projekt fehlt im Archiv (oft ein Submodul).

Fehler mit Datei und Zeile kannst du im Ergebnis anklicken – der Editor springt dann direkt zur Stelle.

Datenschutz & Sicherheit

  • Hochgeladene Projekte werden nur zum Kompilieren verwendet. Der Quellcode wird direkt nach dem Build gelöscht, das Ergebnis nach kurzer Zeit.
  • IP-Adressen werden nicht im Klartext gespeichert, nur als Prüfsumme für das Limit pro Stunde.
  • Pakete werden in einer abgeschotteten Umgebung von nuget.org geladen. Das Kompilieren selbst läuft in einem Container ohne Netzwerkzugang.
  • Die Seite lädt keine externen Skripte, Schriften oder Tracker.

Prepare your server

CounterStrikeSharp runs as an extension of Metamod:Source, so you need both:

  1. Download Metamod:Source (2.x) and extract it into game/csgo/.
  2. In game/csgo/gameinfo.gi, add the line Game csgo/addons/metamod under SearchPaths, right after Game_LowViolence.
  3. Download CounterStrikeSharp (with-runtime the first time) from GitHub and extract it into game/csgo/ as well.
  4. Start the server and type meta list in the console – CounterStrikeSharp should be listed.

First plugin

A plugin is a regular C# project. A demo project is already loaded on the start page – just click Compile now. A minimal plugin:

using CounterStrikeSharp.API.Core;

public class HelloPlugin : BasePlugin
{
    public override string ModuleName => "Hello";
    public override string ModuleVersion => "1.0.0";

    public override void Load(bool hotReload)
    {
        Console.WriteLine("Hello world!");
    }
}

Create new files in the editor with New file. Commands use [ConsoleCommand("css_name")], events use [GameEventHandler].

Packing the project

  • Zip the whole project folder – the .csproj and all .cs files.
  • bin/, obj/ and .git/ are ignored automatically.
  • If your project references another project (e.g. a git submodule), that folder must be in the .zip too. GitHub's “Download ZIP” does not include submodules.
  • If there are several .csproj files, you can pick the main project.
  • A HintPath reference to a local CounterStrikeSharp.API.dll is replaced by the NuGet package automatically.

Which version?

The API version should match the CounterStrikeSharp version on your server. Type meta list or css_plugins list in the server console. When in doubt, use the latest.

Newer CounterStrikeSharp versions require a newer .NET. If your project doesn't match the selected version, the compiler suggests a matching version or offers to switch the target framework.

Installing the plugin

The downloaded .zip is already structured correctly. Extract it into game/csgo/:

game/csgo/addons/counterstrikesharp/plugins/YourPlugin/YourPlugin.dll

Then restart the server or run css_plugins load YourPlugin.

Common errors

Plugin not loading: folder name and DLL name must match. Check the server console or addons/counterstrikesharp/logs/.

CS0246 – type or namespace not found: a NuGet package, using or project reference is missing.

CS0117 / CS1061 – member does not exist: the API changed. The plugin was probably written for an older CounterStrikeSharp version – select that version.

NU1202 – package not compatible: target framework and API version don't match.

CS0006 / project not found: a referenced project is missing from the archive (often a submodule).

Privacy & security

  • Uploaded projects are only used for compiling. Source code is deleted right after the build, the result shortly after.
  • IP addresses are only stored as a hash for the hourly limit.
  • Packages are fetched from nuget.org in an isolated environment; compiling runs in a container without network access.
  • The site loads no external scripts, fonts or trackers.
